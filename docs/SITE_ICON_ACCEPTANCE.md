# Site icon acceptance

The site icon change is complete when:

- browser tabs use the official Mettelo block/node mark;
- the legacy improvised H-style glyph is absent from `app/icon.svg`;
- the icon remains recognisable against light and dark browser chrome;
- the Mettelo Ink, Warm Sand and Value Gold colours are preserved;
- the source brand mark remains separately available for future icon/export work;
- no duplicate `favicon.ico` overrides the Next.js App Router icon;
- CI, build and release gates pass before merge.
