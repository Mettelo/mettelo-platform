# My Mettelo Projects

My Mettelo Projects is the member's cross-project portfolio and transition point into Mettelo Lab. It summarizes current, preparing and completed work without recreating the project workspace.

## Ownership

- **Current/active delivery:** summarized in Projects; execution happens inside Mettelo Lab.
- **Preparing / Team Forming:** remains visible in the portfolio, with plain-language formation status and no Lab entry until the member's real project run is ready and authorized.
- **Completed work:** remains available as member history and may link to My Mettelo Proof when verified contribution evidence for that project exists.
- **Discover:** broad project discovery remains `/projects`.
- **Recommended:** profile-matched project discovery remains `/member/recommended`.

## Data and privacy

Projects uses authenticated member-scoped project memberships, project runs, assigned project tasks and verified contributions. The existing server-only aggregate formation count may be used for orientation, but member Projects does not render other cohort rosters or cross-cohort member details. Authorization for Mettelo Lab remains enforced by the project workspace gate, not by whether a button is hidden.

## Scale and filters

The first portfolio retrieval is intentionally bounded. Search and role/state filters operate on that bounded member portfolio, and completed results are paginated so historical work does not dominate the first viewport.

## Responsive and accessibility contract

The lifecycle order remains Current -> Preparing -> Completed -> Explore. Mobile (`<=480px`) is single-column with the standard Home / Projects / Discover / Proof / More navigation; tablet (`481-1024px`) uses the compact member rail and reflowed controls; desktop (`>=1025px`) keeps a constrained content grid. Interactive controls target at least 44px where applicable, focus is visible, status is textual rather than color-only, reduced motion is respected, and browser QA covers 375, 390, 414, 768, 1024 and representative desktop widths plus 200% text zoom.
